# ESEP Grade Calculator

This library is a simple utility to calculate your grades.

Runtime requirements:
Golang 1.24+

First download Go, if not already set up:
https://go.dev/dl/

To verify version, run the following:
go version

Navigate into the grade-calculator directory and run unit tests:
```
cd grade-calculator/
go test ./...
```

Navigate into the grade-calculator directory and run unit tests with code coverage:
```
cd grade-calculator/
go test -coverprofile=coverage.txt ./...
```
